Landing Page Moderna

Desenvolvimento de uma landing page moderna para uma startup de tecnologia. O objetivo é transformar um layout criado no Figma em uma página profissional, responsiva e otimizada para conversão de leads.

🎯 Objetivo do Projeto

Criar uma landing page com foco em marketing digital, captura de clientes e apresentação dos serviços da empresa.

📋 O que deverá ser feito

  • Converter layout do Figma.
  • Desenvolver HTML e CSS responsivos.
  • Adicionar animações suaves.
  • Criar formulário de contato.
  • Otimizar velocidade do site.
  • Configurar SEO básico.

🛠 Tecnologias Necessárias

  • HTML5
  • CSS3
  • JavaScript
  • Git e GitHub
  • Responsividade
  • SEO

✅ Requisitos

  • Experiência comprovada.
  • Portfólio atualizado.
  • Disponibilidade imediata.
  • Comunicação frequente.

📌 Como realizar o projeto

Após aprovação você receberá o layout completo no Figma, guia de identidade visual e acesso ao material da empresa. O trabalho deve seguir fielmente o design aprovado e ser entregue dentro do prazo definido.
